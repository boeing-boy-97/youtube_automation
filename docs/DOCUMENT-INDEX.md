Rules for this directory:

1. **One question per document.** If a document answers two unrelated questions, it is two documents.
2. **Every file here is listed above.** `npm run verify:structure` fails otherwise, so an unlisted
   document cannot be forgotten.
3. **No dead paths.** Any document that mentions another document by path must have that file; the
   structure check greps for `docs/` mentions and fails on the ones that do not exist.
4. **Dates are absolute** (`2026-11-09`, not "last week"), because documents outlive the person who
   wrote them.
